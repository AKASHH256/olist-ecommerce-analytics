# Olist E-Commerce Analytics

An e-commerce analytics project built using the Brazilian Olist dataset.

## Analysis

- Revenue trends over time
- Revenue by state
- Revenue by payment method
- Product and category analysis
- Customer RFM segmentation
- Delivery and review analysis

## 🔗 Dashboard

Interactive Streamlit dashboard with filters and Plotly visualizations.

**Live Dashboard:** https://olist-ecommerce-sql-analysis-w3qozraszdwuskek2ba8qu.streamlit.app/

## Tools

Python • Pandas • Plotly • Streamlit • Matplotlib • Jupyter Notebook • Git & GitHub

## Dataset

Brazilian E-Commerce Public Dataset by Olist.
